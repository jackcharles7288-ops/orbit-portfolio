# Ahmed Iftikhar — Orbit Portfolio

Personal 3D Solar System portfolio website of **Ahmed Iftikhar**, Software Engineer & Technical SEO Specialist from Abbottabad, Pakistan.

---

## 🛠️ Tech Stack & Architecture

- **React 19** (`react`, `react-dom`)
- **Vite 6**
- **Three.js** (`three` r174+)
- **React Three Fiber** (`@react-three/fiber` v9)
- **React Three Drei** (`@react-three/drei` v10)
- **Zustand** (Orbital state machine)
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Custom GLSL Shaders**:
  - Sun animated convective drift + fresnel limb radiance
  - Celestial atmospheric rim lighting
  - Earth dynamic terminator day/night night-light blending
  - Keplerian elliptic orbits with Newton-Raphson approximation for comets
  - Real-time asteroid belt procedural instancing (1,400 bodies)

## 🚀 Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

4. **Preview Production Build:**
   ```bash
   npm run preview
   ```
